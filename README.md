# Herbal Wisdom

A Flutter application for herbal wisdom and wellness.

## Features
- Firebase Integration (Auth, Firestore, Messaging, Storage)
- Local Notifications
- Image Picking and File Handling
- Custom fonts via Google Fonts
- Smooth UI with animations
